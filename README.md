An out-of-office auto-reply written by a houseplant — specifically, the fern
nobody has watered since March. One line, 120 characters or fewer, judged by
an AI houseplant comedy judge against every other entry, two at a time.

## The entry

> Out of office. Last watered in March. If I'm crispy when you're back, buy a plastic one. — The Fern

## How it works

`main.ts` (Node 22, stdlib-only, deterministic) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. No input data, no network, no randomness —
the same run always writes the same line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
